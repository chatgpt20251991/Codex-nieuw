# GitHub / Codex handoff

Recommended repository name: `eubatterypassport-platform` (private).

The connected GitHub account had no accessible repositories at the time this baseline was prepared, and the available GitHub connector does not expose repository creation.

Once an empty repository exists, this tree can be uploaded as the initial `main` commit. The local source baseline commit is recorded in the release notes/test report, and Codex should start from `AGENTS.md`.

Do not copy only the app folders. The root docs, `infra/`, `.github/`, `scripts/`, `AGENTS.md` and `CODEX_HANDOFF.md` are part of the compliance/security design and must travel with the code.
