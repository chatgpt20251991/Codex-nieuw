# Customer readiness update

This release adds dated NL/EN regulatory FAQs and a scoped service description while preserving the approved visual design. The start checklist is downloadable without submitting contact details. Additional optional intake questions capture role, finished battery, shared BMS, energy, quantities, market timing, countries and update method. Answers are explicitly unreviewed customer declarations, bounded and serialised into the existing message field so the private mail worker remains compatible.

Public intake remains gated by the existing runtime flags, worker health and private credentials. Do not enable it merely because source tests pass. Existing mailbox roundtrip evidence is dated 18 September 2026; PHP transport, cron alert and synthetic intake acceptance still need real-host verification. The legal business identity also needs owner confirmation.

The example QR was generated with the repository's existing qrcode version 1.5.4 and resolves to the public fictional example page. It is not an official identifier profile or Registry receipt. No normative QR/identifier conformity is claimed.

The internal customer workbook, 71-field checklists for three categories, prospective-company research and fictional dossier are maintained outside this public website under docs/customer-readiness. They are not included in the Sites deployment. The generation script validates the public/restricted split and the source map and rejects inconsistent configuration.

Official review: Commission Battery Passport FAQ first edition (September 2026); Registry User Guide v1.03 (16 September 2026), notably pp.48/54; Commission datapoint guidance announcement (21 August 2026). See the website's visible source links and docs/customer-readiness/REGULATORY_REVIEW.md. No production platform, registration flag, evidence gate or authority access rule is changed.
